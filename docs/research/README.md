# Research artifacts

The [English HCI capture analysis](HCI_CAPTURE_ANALYSIS.md) is the canonical technical report about a user-supplied SO S5 btsnoop capture. It is translated from the [original Russian research notes](../ru/research/HCI_CAPTURE_ANALYSIS.md), which remain preserved for source traceability.

The capture itself, the original Mi Home plugin bundle and all credentials are deliberately excluded from this repository. Current protocol controls and limitations are summarized in [the protocol guide](../PROTOCOL.md).

The report describes a **historical capture**; its 0.2.0/0.3.0 version references must not be read as the current integration release.
