# Historical project snapshots

These documents preserve investigations and decisions made before the current general-domain build. They are **not** installation or migration instructions, and their version numbers reflect the dates on which they were written.

Historical UI control names have been **translated to English for readability**; the original Russian labels and complete original text remain recoverable through Git history. Original HCI research measurements and prose are separately retained in the [Russian research source](../ru/research/HCI_CAPTURE_ANALYSIS.md).

For current information, use the [project status](../STATUS.md), [installation guide](../INSTALLATION.md), [compatibility matrix](../COMPATIBILITY.md), [domain migration](../MIGRATION.md), and [documentation language policy](../LANGUAGE_POLICY.md).
