# Совместимость SO / BWJ

[Русская документация](README.md) · [Установка](INSTALLATION.md) · [Технический анализ (англ.)](../MULTI_MODEL_ARCHITECTURE.md)

![Семейство SO: опубликованные возможности и степень проверки](../assets/model-family.svg)

Сходство опубликованных MIoT-свойств **не гарантирует** одинаковую BLE-аутентификацию или работу команд. На реальном S5 ранее удалось пройти авторизацию Xiaomi и управлять устройством. Другие модели — экспериментальные кандидаты.

| Модель | Идентификатор Xiaomi | Возможности по MIoT | Статус |
| --- | --- | --- | --- |
| **S5** | `bwj.diffuser.s5` | Питание, распыление, RGB, батарея, режим `3.4 = 0` | Ранее проверен пользователем |
| S2 | `bwj.diffuser.h10` | Питание, распыление, RGB | Эксперимент |
| S6 | `bwj.diffuser.s6` | Питание, распыление, RGB | Эксперимент |
| S7 | `bwj.diffuser.bw11` | Питание, распыление, RGB | Эксперимент |
| S8 | `bwj.diffuser.s8` | Питание, распыление, RGB | Эксперимент |
| S9 | `bwj.diffuser.s9` | Питание, распыление, RGB | Эксперимент |
| S1 Pro | `bwj.diffuser.s1pro` | Питание, распыление, RGB, температура при наличии уведомления | Эксперимент |
| S1 | `bwj.diffuser.k09` | Питание, распыление; без RGB | Эксперимент |
| S19 | `bwj.diffuser.s19` | Питание, распыление; без RGB | Эксперимент |

**Как проходит проверка:** сначала находится точное Bluetooth-имя (или пользователь вводит адрес), затем в Xiaomi Cloud выбирается конкретная модель, и её токен проверяется на физическом BLE-устройстве. Для модели, отличной от S5, пользователь отдельно подтверждает экспериментальное подключение. Даже успешная криптографическая авторизация не подтверждает правильность всех команд.

Во всех девяти опубликованных схемах для паузы предусмотрено значение `3.4 = 0`. Поэтому экспериментальные модели получили переключатель нулевой паузы, но **его фактическая механическая работа не проверена**. Не используйте это поведение в автономных автоматизациях без испытания устройства.

**Не входит в поддержку:** произвольные устройства Xiaomi с FE95, другие BLE Mesh-протоколы и неизвестные диффузоры. Если прибор виден в Xiaomi Miot, это само по себе не означает наличие локального транспорта управления.

Для подтверждения новой модели нужны реальные тесты BLE-аутентификации, включения и выключения, чтения состояний, распыления, повторного подключения после перезапуска и работы без доступа к интернету. Публично передавать токены, MAC-адреса и ссылки OAuth нельзя.
